# Проєкт: SSR-сайт польською під Google Ads

Next.js 16 (App Router, React Server Components), TypeScript, без Tailwind —
власна дизайн-система на CSS-змінних + CSS Modules. Контент валідується через
Zod-схеми (`lib/content/schema.ts`), щоб помилка в даних падала на білді, а не
мовчки губилась на сторінці.

Тема: одиночна браузерна стратегія (турова економічна гра). Без бренду, без
лого, без назви гри — за вимогою ТЗ. Усі тексти й ілюстрації написані під цей
проєкт з нуля.

## Структура

- `app/page.tsx` — головна сторінка (максимально наповнена контентом: hero,
  опис проєкту, 4 філософських принципи, 6 механік з ілюстраціями, 4 сценарії,
  вбудований інтерактивний прототип, журнал розробки, FAQ, фінальний CTA).
- `app/graj/` — окрема сторінка з тим самим інтерактивним прототипом гри
  (реально грабельна демка на hex-сітці, стан у React, без бекенду).
- `app/mechanika/` — розширена документація механік + таблиця ресурсів +
  приклади технологій по ерах.
- `app/faq/`, `app/kontakt/`, `app/regulamin/`, `app/polityka-prywatnosci/` —
  сторінки, обов'язкові для проходження модерації Google Ads (контакти,
  умови використання, політика приватності з розкриттям cookie).
- `components/HeksagonalneTlo.tsx` — рукописна canvas-анімація hex-сітки в
  hero (без ігрових бібліотек).
- `components/PoligonDemo.tsx` + `lib/poligon-silnik.ts` — логіка міні-гри
  (генерація плати, збір ресурсів, кінець ходу, умови перемоги/поразки).
- `public/ilustracje/*.svg` — 6 згенерованих скриптом векторних ілюстрацій
  (мапа з туманом розвідки, дерево технологій, потік ресурсів, три шкали
  настрою, пори року з попередженням про кризу, архів спадщини між партіями).
- `app/icon.svg` — унікальна фавіконка (абстрактний геометричний знак, не
  логотип).

## Домен (плейсхолдер)

Реальний домен ще не наданий. До заміни сайт використовує заглушку в
`lib/site-config.ts` (`https://domena-do-podmiany.pl`). Коли домен буде
відомий, просто задайте змінну середовища у Vercel:

```
NEXT_PUBLIC_SITE_URL=https://ваш-домен.pl
NEXT_PUBLIC_CONTACT_EMAIL=kontakt@ваш-домен.pl
```

Це автоматично підхопиться в metadata, sitemap.xml, robots.txt, JSON-LD і
формі контактів — ніде більше нічого міняти не треба.

## Локальний запуск

```
npm install
npm run dev
```

## Перевірка перед деплоєм

```
npm run typecheck
npm run lint
npm run build
```

Усі три команди проходять чисто на момент здачі проєкту.

## Деплой на Vercel

1. Імпортувати репозиторій у Vercel (framework визначиться автоматично як
   Next.js завдяки `vercel.json`).
2. Додати змінні середовища `NEXT_PUBLIC_SITE_URL` і
   `NEXT_PUBLIC_CONTACT_EMAIL`, коли буде відомий домен.
3. Деплой без додаткових налаштувань — команди збірки вже прописані у
   `vercel.json` (`next build` / `next start` не потрібен, Vercel сам
   обслуговує SSR-функції).

## Що навмисно НЕ додано

- Жодного тега Google Ads / Google Analytics — ID рекламного акаунту не
  надано. Місце для підключення описано в `app/polityka-prywatnosci/page.tsx`
  (розділ про майбутні аналітичні cookie) — коли з'явиться ID, скрипт
  додається в `app/layout.tsx` за принципом, що спрацьовує тільки після
  згоди в банері cookie (`components/ZgodaCookies.tsx`).
- Жодного бренду, назви гри чи логотипу — за прямою вимогою ТЗ.
- Жодних платних переваг / елементів азарту — гра суто стратегічна,
  одиночна, без порівняння результатів між гравцями.
